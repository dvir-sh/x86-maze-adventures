# Maze Adventures

A maze game built from scratch in **x86 Assembly**, complete with a custom level editor and full map import/export support.

## Gameplay

Guide a red cube through a maze to reach the exit without touching the walls. Collect stars for bonus points, dodge (or trigger) bombs that can blast through walls, and race against a "void" that slowly closes in from the side of the screen. Three modes are available - Peaceful, Normal, and Hardmode - with an optional bomb toggle for extra challenge.

## 🗺️ Map Editor & Import/Export

The core feature of this project is a built-in map editor with full import/export support:

- **Create** your own maze with simple mouse controls - draw walls, set the frame size, place the exit, and move between levels.
- **Export** your finished map to a single file saved straight into the game folder.
- **Import** maps made by others - just drop their exported file into the game folder and load it from the "custom maps" screen.
- **Share** any map with a friend by sending them that one exported file - no extra tools needed.

## About this project

This was built entirely in x86 Assembly, by hand, before LLMs were even remotely competent at writing Assembly code. As a result, it's roughly 90% human-written - no AI co-pilot to lean on for this one.
